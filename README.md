# Запомню — бесплатные карточки для iPhone

Веб-приложение (PWA) для интервальных повторений. Открывает колоды Anki `.apkg`
(старый и новый формат, с картинками и звуком), работает без интернета, ставится
на экран «Домой» iPhone как обычное приложение. Все данные хранятся только на устройстве.

## Возможности
- Импорт `.apkg` / `.colpkg`: обычные карточки, обратные, cloze (пропуски), ввод ответа, подсказки, фуригана, картинки, аудио, вложенные колоды.
- Повторение с кнопками «Снова / Трудно / Хорошо / Легко» (алгоритм в духе SM-2, как в классическом Anki), лимиты в день, шаги изучения, отмена ответа.
- Повторный импорт той же колоды не сбрасывает прогресс.
- Резервная копия всего прогресса в один .zip и восстановление из неё.
- Светлая и тёмная тема.

## Публикация на GitHub Pages
1. Загрузите содержимое этой папки в корень публичного репозитория.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на iPhone
1. Откройте адрес сайта в **Safari**.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Запускайте с иконки «Запомню». Колоды импортируются через меню ⋯ → «Импортировать колоду».
